# Figures for the VeriLinkOS Academic Paper

This directory contains the diagrams and illustrations referenced in the academic paper.

## Planned Figures

1. **architecture.png** — VeriLinkOS Five-Layer Architecture
2. **lifecycle.png** — Component Lifecycle and the 12-Stage Action Chain
3. **trust-triangle.png** — The Trust Triangle: Identity, Governance, Evidence
4. **vap-flow.png** — VAP Receipt Generation and Verification Flow
5. **guardian-flow.png** — Guardian Enforcement Decision Flow

## Current Status

These diagrams are under development. The paper's Markdown file contains ASCII representations that serve as placeholders until the final vector graphics are ready.

## Usage

Once added, reference these figures in the paper as:

```
![VeriLinkOS Architecture](figures/architecture.png)
```
